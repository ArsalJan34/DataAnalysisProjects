# Date String Manipulations & Lightning Strikes Analysis

## 📌 Overview

This project demonstrates data manipulation and exploratory data analysis (EDA) on NOAA lightning strike data (2016–2018). It focuses on parsing datetime objects, converting formats using `strftime`, performing temporal aggregations (weekly and quarterly), and generating formatted visualizations using `matplotlib` and `seaborn`.

## 🛠️ Key Python Techniques

- **Datetime Parsing:** Converting raw strings to `datetime64` types.
- **String Formatting (`dt.strftime`):** Extracting week (`%V`), month (`%m`), quarter, and year (`%Y`).
- **Data Aggregation:** Grouping by time frequencies and summing strike totals.
- **Data Visualization:** Creating annotated single-variable and grouped bar charts.

# Unicorn Companies - Exploratory Data Analysis (EDA)

## Project Overview

This project performs an Exploratory Data Analysis (EDA) on a dataset of high-valuation startup companies ("Unicorns") valued at over $1 Billion. The goal is to discover trends regarding how long companies take to reach unicorn status and which industries command the highest valuations.

## Tools & Libraries

- **Python 3.x**
- **Pandas** (Data cleaning & manipulation)
- **Matplotlib** (Data visualization)
- **VS Code / Jupyter Notebooks**

## Key Findings

1. **Time to Unicorn Status:** The duration required to reach a $1B valuation varies significantly across industries. Sectors like Health and Fintech often require more development time compared to Consumer & Retail.
2. **Valuation Leaders:** Industries such as Artificial Intelligence, Fintech, and E-commerce demonstrate higher peak valuations among early unicorns.

# 2. Course 3 Modules

## Module 1 — Introduction to Statistics

Learn the foundational role of statistics in data science.

### Main Topics

- Descriptive statistics
- Measures of central tendency
- Measures of dispersion
- Measures of position

---

## Module 2 — Probability

Learn fundamental concepts of probability.

### Probability Rules

- Complement
- Addition
- Multiplication
- Conditional probability
- Bayes's theorem

### Probability Distributions

- Binomial distribution
- Poisson distribution
- Normal distribution

---

## Module 3 — Sampling

Learn how sampling is used in data work.

### Main Topics

- Inferential statistics
- Population vs. sample
- Sampling process
- Sampling methods
- Benefits and drawbacks of sampling methods
- Sampling distributions for means
- Sampling distributions for proportions

---

## Module 4 — Confidence Intervals

Learn how confidence intervals describe **uncertainty in estimates**.

### Main Topics

- General procedure for constructing confidence intervals
- Correct interpretation of confidence intervals
- Confidence intervals for means
- Confidence intervals for proportions

---

## Module 5 — Introduction to Hypothesis Testing

Learn how hypothesis testing helps determine whether results are **statistically significant**.

### Main Topics

- General hypothesis-testing procedure
- Interpreting hypothesis-test results
- One-sample tests
- Two-sample tests

---

## Module 6 — Course 3 End-of-Course Project

Use statistical knowledge to conduct a **statistical test based on a workplace scenario**.

### Goal

Produce a tangible artifact that can be:

- Added to your professional portfolio
- Presented to future employers
